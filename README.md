# Dimensional Inventories Extension: Trinkets

An extension for [Dimensional Inventories](https://modrinth.com/mod/dimensional-inventories) providing support for the [Trinkets](https://modrinth.com/mod/trinkets) mod.

## Version Compatibility

This extension mod depends on a preliminary extension API from the base mod, Dimensional Inventories, as well as the [Trinkets API](https://github.com/emilyploszaj/trinkets/wiki/Trinkets-API).
Known compatible versions are listed on each extension release.
